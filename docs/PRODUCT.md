# Eterno — Product Specification

## 1. Executive Summary
Eterno is an enterprise developer intelligence and college coding challenge platform. It eliminates manual, self-reported coding claims by verifying student problem-solving activity directly through platform APIs (starting with LeetCode) and synthesizing cross-platform developer engagement into a unified activity heatmap and institutional analytics dashboard.

## 2. Core Product Questions
1. **What coding activities has a developer completed across platforms?** (Unified multi-source activity tracking).
2. **Which students solved the coding challenges assigned by their college?** (Automated server-side verification).
3. **Who is consistently solving problems instead of cramming occasionally?** (Consistency streaks, active-day tracking).
4. **Which students, groups, departments, and colleges are performing best?** (Deterministic multi-level leaderboards).
5. **How is each developer improving over time?** (Historical solve progression and platform stats).

## 3. User Roles & Personas
- **Platform Administrator**: Supervises all institutions, monitors provider health, manages system operations.
- **College Administrator**: Manages college challenges, students, departments, batches, and exports reports.
- **Group Administrator**: Leads coding clubs, contest training groups, and group-specific challenges.
- **Student / Developer**: Solves problems, links accounts with cryptographically verifiable proofs, tracks streak and rank.
